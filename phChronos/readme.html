Chronos

Runs SOAR playbooks on a schedule without creating containers. The asset's ingest schedule is the timer; a custom list is the job registry; every run is attached to one container you create yourself and reuse forever.

Before configuring an asset

  1. Create one container for scheduled runs to attach to, and note its ID.
  2. Create an automation user with a role that can run playbooks, and copy its ph-auth-token.
  3. Create a custom list, one playbook per row in the first column. A row may be repo/Playbook Name or a numeric playbook ID. A row starting with # is skipped.

Scheduling

Set the interval or cron expression on the asset's Ingest Settings tab. For more than one cadence, create one asset and one custom list per interval. The label on the ingest tab is required by the platform and unused by this app.

Test connectivity

Checks reachability, then the token and container, then the custom list, and reports the row count. The check that fails names the field to fix.
